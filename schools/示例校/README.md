# 示例校数据包（占位 · 用来跑通流水线）

这是给陌生学校准备的**最小可运行样本**：2 只虚构的猫 + 程序生成的占位图，
用途是让你在 15 分钟内亲眼看到「CSV + 照片 → 星图 HTML」的完整过程。

## 目录

```
示例校/
├─ data/
│  ├─ 猫咪名册.csv            # 12 列名册，2 行（CAT-001/CAT-002）
│  ├─ build_meta.json         # 校名、版本、仓库链接等构建参数
│  └─ 归并决策摘要_示例.md     # 占位摘要（正式普查请替换）
├─ photos/
│  ├─ demo-cat-001.jpg        # ⚠ 程序生成的占位图，不是真实猫照
│  └─ demo-cat-002.jpg        # ⚠ 同上
└─ map/
   └─ 示例校园星地图.jpg       # 程序生成的星野底图（非真实地图）
```

## 构建

在仓库根目录：

```bash
uv run --with pillow tools/build.py --pkg schools/示例校 --out dist/示例校
# 双击 dist/示例校/示例校喵星图.html
```

## 换成你们学校时

1. 整包复制为 `schools/<你的学校短名>/`；
2. 删除两个 `demo-*.jpg` 占位图和本 README 的占位说明；
3. 按 [`../../docs/快速上手.md`](../../docs/快速上手.md) 填名册、放照片、换底图；
4. 拍摄与普查规范见 [`../../docs/普查与拍摄规范.md`](../../docs/普查与拍摄规范.md)。
