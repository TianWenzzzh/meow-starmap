# 10 分钟做出你们学校的猫咪星图（图文教程）

> 目标：**不写一行代码**，用示例校数据跑通整条流水线，得到一份双击就能
> 打开的离线星图 HTML。之后把数据换成你们的，就是你们学校的版本。
> 前置：装好 [uv](https://docs.astral.sh/uv/getting-started/installation/)
> （一条命令）和 git；Windows / macOS / Linux 都行。

## 0 · 克隆仓库（1 分钟）

```bash
git clone https://github.com/TianWenzzzh/meow-starmap.git
cd meow-starmap
```

## 1 · 认识数据包（2 分钟）

打开 `schools/示例校/`——这就是一个学校数据包的全部：

```
schools/示例校/
├─ data/猫咪名册.csv     ← 12 列名册（编号/昵称/毛色/出没区域…）
├─ photos/*.jpg          ← 每只猫的代表照（文件名 = 名册"代表照片文件"列）
└─ map/校园地图.jpg       ← 一张校园底图（没有也能跑，会自动生成星野底图）
```

名册 12 列的填写规范见 [快速上手](快速上手.md)；「军衔/工位」是拟人化玩法，
「出没区域」决定星星落位，「照片数量」决定星等亮度。

## 2 · 一条命令构建（3 分钟）

```bash
uv run --python 3.12 --with pillow python tools/build.py --pkg schools/示例校 --out dist
```

输出长这样：

```
✓ 示例校喵星图 构建完成 → dist
  猫 2 只 · 照片 2 个文件（重压缩 0 张）· 底图原样 · 分片 1 个 · ...
  打开方式：直接双击 示例校喵星图.html（全离线，无需服务器）
```

首次运行 uv 会自动准备 Python 3.12 和 Pillow，不用装任何环境。
想让照片**点开才加载**（学校大、照片多时首屏更快）：

```bash
uv run --python 3.12 --with pillow python tools/build.py \
  --pkg schools/示例校 --out dist --photo-loading lazy
```

## 3 · 双击验收（2 分钟）

打开 `dist/示例校喵星图.html`，检查五件事：

1. 极光开场屏 → 点「进入星图」
2. 星星落在地图上，颜色对应毛色，大小对应实拍数
3. 点任意星星 → 档案卡（照片/军衔/小传）
4. 顶部「影廊」→ 灯箱看大图（lazy 模式此时才开始拉照片分片——正常）
5. 断网再刷新一次，依然能玩——这是本项目「军训断网也能用」的立身之本

## 4 · 换成你们学校的数据（2 分钟起步）

```bash
cp -r schools/示例校 schools/你们的校名缩写
# 编辑 data/猫咪名册.csv（12 列照抄表头），把 photos/ 换成你们的照片
uv run --python 3.12 --with pillow python tools/build.py \
  --pkg schools/你们的校名缩写 --out dist
```

数据要求三条：**每只猫至少 1 张可辨识照片；同一只猫的多张照片归并成一条
记录并把取舍写进 `归并决策摘要.md`；拿不准的置信度标低或直接不收**。

## 5 · 玩大之后（可选）

- 想挂上 [多校展示墙](https://tianwenzzzh.github.io/meow-starmap/gallery/)：
  按 [PR 指南](PR指南.md) 提交，或填
  [种子学校申请](https://github.com/TianWenzzzh/meow-starmap/issues/new?template=school-application.md)
  让作者协助构建（首批 3–5 所）
- 想要「在线生成器」：那是[喵星图工厂](https://github.com/TianWenzzzh/catgalaxy-factory)
  （FastAPI），渲染内核与本项目同源
- 常见坑：CSV 用 Excel 存成了 GBK（用 UTF-8 另存）、照片文件名带全角空格、
  底图太大（长边 1920 足够）——报错信息里都有人话提示
