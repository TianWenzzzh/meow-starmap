# 复刻自检清单（打包 / 提 PR 前过一遍）

在中北版复刻清单基础上，按本仓库构建管线改写。每项都要能当场验证。

## 一、数据层

- [ ] 名册编号连续无复用；弃用编号留空且在归并摘要里有记录
- [ ] 每只猫的「代表照片文件」在 `photos/` 里真实存在、能打开
- [ ] 每只猫都能在归并摘要/台账里找到照片证据链（关联照片编号）
- [ ] 置信度「低」的个体全部弃用并留痕；「中」的合并有推断依据
- [ ] 无任何含人脸的照片；投喂人/拍摄人私人信息未泄露
- [ ] 小传内容只来自照片可见信息与蹲点核实，无虚构
- [ ] 各出没区都有归属猫；个别区确实没猫就在摘要里写明「暂未发现」
- [ ] 数据包总体积 < 15MB，无单文件 > 40MB

## 二、构建层

- [ ] `uv run --with pillow tools/build.py --pkg schools/<校名> --out …`
      输出 `✓ 构建完成`，无告警漏看
- [ ] HTML 全文搜索 token 残留（`__[A-Z_]+__`）为 0——构建器本身会硬失败，
      仍建议人工再搜一遍
- [ ] 可选：`node tools/check_html_scripts.mjs <产物目录>` 报告「失败 0」
- [ ] 产物是 `<产品名>.html + assets/ + data/`，整体拷贝可离线打开

## 三、浏览器功能层（手机 + 电脑各一遍）

- [ ] 开场屏：校名、统计行、底部署名行（含仓库链接）显示正确
- [ ] 点「入 夜 寻 喵」后星图主界面出星，星数 = 名册只数
- [ ] 随机点开一只猫卡：军衔、特征、小传、照片、地点齐全
- [ ] 影廊灯箱：能开、能左右翻、能关；照片方向正确（EXIF 已矫正）
- [ ] 本命猫测试 / 喵星护照面板能打开
- [ ] 喵星分享卡能导出 PNG，底部有原创署名行
- [ ] 搜索、毛色筛选、星域/星宿、今日偶遇至少各点一次
- [ ] 星位：有固化坐标的落在合理点位；无固化坐标的显示「随机分布 · 待校准」
- [ ] 手机浏览器（iOS Safari / 安卓 Chrome）不黑屏、不卡成幻灯片
      （特效会自动降档，属正常）

## 四、文案与品牌层

- [ ] 全局搜「中北/NUC/示例校/demo」，确认该换的都换了
      （底图角落的文字水印也别忘了）
- [ ] `build_meta.json` 的 school/product/en/ls_prefix/repo_url 已改
- [ ] 底图来源合法（学校公开授权 / OSM / 自绘），来源写进学校 README
- [ ] 学校 README 按 PR 指南模板填好，许可声明与拍摄者授权齐全
- [ ] localStorage 前缀（ls_prefix）与其他学校不冲突

## 五、传播层（如要公开发布）

- [ ] 在线版本可访问（GitHub Pages 等），仓库 README 链接互链
- [ ] 对外口径统一：公益开源、照片署名、非商业、同协议共享
- [ ] 发布前给拍摄者看过成片，授权话术留痕（微信/邮件截图存档）
