# 种子学校流程：从申请到上墙（四步）

> 面向首批 3–5 所协作学校。全程免费、开源、离线可用；你们的照片与数据许可
> 是 CC BY-NC-SA 4.0——**权利永远归拍摄者与普查团队**，可随时要求下架。

## 四步总览

```
① 申请 → ② 普查 → ③ 构建 → ④ 上墙
 (issue)   (你们)   (你们或我们)   (PR 合并即上线)
```

## ① 申请（10 分钟）

填 [种子学校申请 issue](https://github.com/TianWenzzzh/meow-starmap/issues/new?template=school-application.md)。
首批筛选只看三条：**有普查数据（或明确计划）、有拍照人力、有发布渠道**。
48 小时内会有人回复，给出针对你们学校大小的普查规模建议（参照：中北大学
76 只用了 194 张实拍、约两个月课余时间）。

## ② 普查（1–8 周，量力而行）

- 名册模板：[`12_跨校复制包` 的 12 列契约](https://github.com/TianWenzzzh/meow-starmap/blob/main/docs/快速上手.md)
  （编号/昵称/军衔/工位/毛色/特征/代表照片文件/照片数量/出没区域/关联照片编号/置信度/备注）
- 拍摄规范：横拍、对焦在脸、每只猫至少 1 张可辨识照；**不收录含人脸照片**
- 归并纪律：同一只猫多张照片要归并成一条记录，每条取舍写进
  `归并决策摘要.md`（这是本项目「数据可溯源」卖点的核心，模板见示例校）
- 置信度诚实：拿不准的标「低」或直接不收——**小而真 > 大而假**

## ③ 构建（半天，两条路选一）

- **自己动手**：[快速上手](https://github.com/TianWenzzzh/meow-starmap/blob/main/docs/快速上手.md)
  → `uv run --python 3.12 --with pillow python tools/build.py --pkg schools/你们的校名缩写 --out dist`
  → 本地双击验收 → 按 [PR 指南](https://github.com/TianWenzzzh/meow-starmap/blob/main/docs/PR指南.md) 提交
- **申请协作**：在申请 issue 里说明「数据齐了，需要构建协助」，项目作者会
  fork 你们的临时数据仓、代跑构建与浏览器冒烟，产物证据回贴到 issue 里确认

## ④ 上墙（PR 合并即上线）

合并后自动触发：多校展示墙加卡片、GitHub Pages 上线 `https://…/你们学校/`、
-release 打点。之后任何照片权利人要求下架，开 issue 即可，48 小时内处理。

## 给首批 3–5 所的承诺

- 项目作者逐校陪跑普查设计与归并（issue 或视频通话）
- 你们的 `归并决策摘要.md` 会作为「满分卖点」样本被对外展示（可匿名）
- 星图内的原创署名行保留项目溯源（这是唯一不可协商项），其余文案可定制
