# 普查与拍摄规范

来自中北大学 194 张实拍、76 只在编的实战沉淀。原则只有一句：
**宁缺毋滥**——疑似重复、画质不够、身份存疑的一律不收，每条取舍都写下理由。

## 一、普查流程（1-2 个周末）

1. **划区**：先把校园划成 8-12 个出没区（宿舍楼、食堂、教学楼、操场……），
   每区至少蹲一个傍晚（17:30-19:30 是猫最活跃的时段）。
2. **逐张记录**：一台手机拍照 + 一份台账（纸笔或手机备忘录均可），
   每张照片当场记下：`批号-序号 | 时间 | 地点（区+精确点位）| 猫的临时特征`。
   批号按日期编，如 `1017批:03`。
3. **归并**：普查结束后，把同一只猫的多次出现合并成一个编号（CAT-001…）。
   合并依据写进归并决策摘要：同框对比、特征组合（花色+伤口+尾环等）、
   固定点位习性；只有一条弱依据的标「中」并写明推断，无依据的不收。
4. **建档**：填 12 列名册（字段释义见 [快速上手](快速上手.md) §4）。
5. **自检**：提交前过 [复刻自检清单](复刻自检清单.md)。

台账模板（可自由复制）：

```
1017批:01  2026-10-17 18:02  东苑食堂门口石台  胖橘/粉鼻/侧躺露肚
1017批:02  2026-10-17 18:05  东苑食堂门口石台  同上（同一只连拍）
1017批:03  2026-10-17 18:20  三教台阶          狸花/白手套/左耳缺口
```

## 二、拍摄规范

1. **代表照片**：每只猫选 1 张最清晰的正脸或特征明显角度
   （围脖 / 手套 / 尾环 / 伤疤都是身份证据）。
2. **尺寸体积**：手机原图直接交即可，构建器自动压到长边 1200px；
   手工预处理的话目标 800-1200px、100-200KB/张（75 张整包约 3-8MB）。
3. **内容红线**：
   - 不收录任何**含人脸**的照片（合影裁掉或弃用）；
   - 不拍、不公布**投喂人/拍摄人**的个人信息；
   - 不诱导、不追赶、不为拍照堵猫洞；猫表现出应激（耳压低、哈气）就停手。
4. **文件名**：保留相机/微信原始文件名，不要重命名——归并溯源链靠它维系。
5. **方向**：竖拍横拍都行，构建器会按 EXIF 自动矫正；修图软件另存丢了 EXIF
   也没关系，肉眼方向正确即可。
6. **底图**：推荐校园地图夜间化（暗蓝底、道路与建筑浅描、标注猫点参照地名），
   长边 1920px；手绘草图扫描后调暗也可以。底图须有合法来源
  （学校公开地图、OpenStreetMap 自渲、自己手绘）。

## 三、数据红线（可信度的根本）

- 每只猫必须有**照片证据链**：代表照 + 关联照片编号可溯源到台账；
- 置信度「中」的合并必须写明推断依据；「低」的弃用并在摘要留痕；
- 小传只写照片能看到 + 蹲点核实的内容，**不虚构行为故事**；
- 编号一经弃用（发现是重复个体、猫离校等）留空不复用；
- 照片版权归拍摄者，收录前征得同意；公益开源不改变权利归属，
  拍摄者可随时要求下架（话术见仓库外的人工物料模板）。

## 四、安全与边界

- 不投喂禁喂区（教学楼内、实验室附近）；遵守学校管理规定；
- 不公布猫的精确窝点（尤其是幼猫窝），公开版点位只写到「楼栋/片区」；
- 发现伤病猫优先联系本地救助组织，普查不替代救助。
