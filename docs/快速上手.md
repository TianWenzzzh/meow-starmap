# 快速上手：30 分钟给你们学校做出一张喵星图

面向第一次接触本项目的同学。不需要前端基础，会用命令行、会填表格即可。

## 0. 你需要什么

- 一台电脑（Windows / macOS / Linux 都行）
- [uv](https://docs.astral.sh/uv/)（Python 包管理器；装好它就够了，不用单独装 Python/Pillow）
- 一部手机（拍猫用）

> 全流程离线可用：只有安装 uv 和下载本仓库需要联网，构建与浏览都不需要网络
> （军训断网、寝室断网都不影响）。

## 1. 拿到仓库（2 分钟）

```bash
git clone https://github.com/TianWenzzzh/meow-starmap.git
cd meow-starmap
```

或者在仓库页面点 Code → Download ZIP 解压。

## 2. 先用示例校跑通一次（5 分钟）

仓库自带一个虚构的「示例校」数据包（2 只猫 + 占位图），先确认你的环境没问题：

```bash
uv run --with pillow tools/build.py --pkg schools/示例校 --out dist/示例校
```

看到 `✓ 示例校喵星图 构建完成` 后，双击打开
`dist/示例校/示例校喵星图.html`，点「入 夜 寻 喵」，能看到 2 颗星即成功。

## 3. 复制一份你们学校的数据包（2 分钟）

把 `schools/示例校/` 整个复制为 `schools/你们的校名/`：

```
schools/星云大学/
├─ data/
│  ├─ 猫咪名册.csv        # ← 用 Excel/表格软件填
│  ├─ build_meta.json     # ← 改校名等参数
│  └─ 归并决策摘要_示例.md  # ← 改名并按实填写（可先删）
├─ photos/                # ← 放代表照（删掉 demo 占位图）
└─ map/
   └─ 示例校园星地图.jpg    # ← 换成你们学校的底图
```

## 4. 普查与填名册（1-2 个周末，首次上手可先少量）

1. 带着手机在校园里拍猫，边拍边记（格式见 [普查与拍摄规范](普查与拍摄规范.md)）；
2. 同一只猫的多张照片归并成一个编号，取舍理由写进归并决策摘要；
3. 打开 `data/猫咪名册.csv`（UTF-8 编码，Excel 选「数据→从文本/CSV」打开可避免乱码），12 列照表头提示填：

| 列名 | 填什么 |
|---|---|
| 编号 | CAT-001 起连续编号；弃用的编号留空、不要复用 |
| 昵称 | 有梗好记，不含真实人名 |
| 军衔 | 趣味职级体系（上校/中士…，也可自创体系） |
| 工位 | 趣味职务，如「东苑食堂门口安保队长」 |
| 毛色 | 全橘/橘白/狸花/三花/纯黑/纯白/奶牛…（决定星的颜色） |
| 特征描述 | 2-4 个一眼可辨特征，供人实地对照 |
| 代表照片文件 | photos/ 里的文件名，含扩展名 |
| 照片数量 | 归并到这只猫的照片总张数 |
| 出没区域 | 你们校园的地名（如「东苑食堂门口」） |
| 关联照片编号 | 归并溯源依据（批号:编号） |
| 置信度 | 高/中/低；低置信度建议不收 |
| 备注 | 推断依据、待确认事项 |

军衔、毛色分组、亮度、小传等派生字段由 `build.py` 自动推导
（规则来自中北版实战沉淀，见工厂 SPEC），你只填这 12 列原始事实。

## 5. 放照片与底图

- 每只猫 1 张代表照，放 `photos/`，**用手机/微信原始文件名**，与名册列一致；
  构建器会自动做 EXIF 旋转矫正、长边压到 1200px；
- 底图放 `map/`：推荐你们校园地图的夜间化版本（暗底、只留道路与建筑轮廓），
  长边 1920px 即可。没有底图时可先用深色星野底图占位。

## 6. 改 build_meta.json

```json
{
  "school": "星云大学",
  "product": "星云大学喵星图",
  "en": "STELLAR U CAT GALAXY",
  "version": "v1.0",
  "survey_date": "2026-10",
  "ls_prefix": "stellar",
  "repo_url": "https://github.com/<你的组织或账号>/meow-starmap"
}
```

- `ls_prefix`：浏览器本地存档键的前缀，每所学校用不同短名，互不冲突；
- 里程碑（10/30/50/76 只）、星域星宿等不填则由构建器按数据自动生成。

## 7. 构建与自检

```bash
uv run --with pillow tools/build.py --pkg schools/星云大学 --out dist/星云大学
node tools/check_html_scripts.mjs dist/星云大学      # 语法门禁（可选，需 Node 18+）
```

打开产物逐项过一遍 [复刻自检清单](复刻自检清单.md)。

## 8. 分享与回馈

- 产物是**一个 HTML + 一个 assets 文件夹**，整体拷给同学即可离线打开；
  也可放任意静态托管（GitHub Pages、校园服务器、U 盘）。
- 愿意公开你们的数据时，按 [PR 指南](PR指南.md) 提 PR，你的学校会出现在
  [多校展示墙](https://tianwenzzzh.github.io/meow-starmap/gallery/) 上。

## 常见问题

- **双击 HTML 照片不显示？** 检查 `assets/` 文件夹是否与 HTML 一起整体拷贝。
- **Excel 另存后中文名乱码？** 保存时选「CSV UTF-8」；本项目名册统一 UTF-8。
- **星的位置能手动调吗？** 页面右上角「⋯ → 校准位置」可拖星，校准结果存在
  自己浏览器里，可「导出校准数据」发回给维护者固化进数据包。
- **照片会不会被压缩得很厉害？** 构建器对长边 ≤1200px 且体积合格的 JPEG
  原样嵌入，不重编码；只有超限/方向错误时才处理。
