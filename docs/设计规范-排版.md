# 设计规范 · 排版（v30 起）

> 迭代 1（2026-09-18）产出，v31（字栈顺序修正）修订。本文回答三个问题：现在产物里**每一个字体声明**
> 是什么、为什么、以后怎么改。改动模板排版必须走**当代**生成脚本（现役 =
> `tools/make_v31_baseline.py` 的 `U_PATCHES`；每迭代一代新建 make_vXX 并把上一代
> 模板冻结为 fixtures 快照）——确定性补丁 + 次数断言，禁止手改 3300 行模板或 golden。

## 一、字体栈（全文仅 2 处显式声明，其余继承）

| 位置 | v31 字体栈 | 说明 |
|---|---|---|
| `html,body`（全局） | PingFang SC → Microsoft YaHei → HarmonyOS Sans SC → MiSans → Source Han Sans SC → Noto Sans CJK SC → sans-serif | macOS/iPad 首选苹方；Windows 命中雅黑（兜底字体在雅黑之后，不劫持）；Linux 命中思源/Noto（雅黑/HarmonyOS/MiSans 在 Linux 均不存在）——**全部系统自带，零下载，离线红线不破** |
| SVG `<text>`（寻猫海报「喵」字） | 同上去引号版 | SVG 属性不支持引号包裹族名，用逗号直列 |

主题系统的 `title_font/body_font`（Kaiti SC 等）经 `__THEME_CSS__` 注入，
优先级高于全局栈；空值即回退上表。

**红线**：不许引入外部字体文件（@font-face/在线字体）——离线可用是立身之本。
新增兜底只能往栈里**追加**系统字体，且必须排在 Windows 首选（微软雅黑）**之后**、
保持「macOS/Windows 首选不变」（否则历史产物观感漂移，违反字节一致性纪律）。
v31 即因此修正：v30 曾把 HarmonyOS Sans SC / MiSans 插到雅黑之前，装有这两款字
的 Windows 机器会从雅黑漂走。顺序以本表为准，改动必须走 `make_v31_baseline.py`。

## 二、字号分布（v30 实测 117 处，未强制归一）

| 档 | 值 | 主要用途 |
|---|---|---|
| 微 | 9.5 / 10 / 10.5px | 角标、脚注、海报版权行 |
| 小 | 11 / 11.5 / 12 / 12.5px | UI 主体：chips、面板、列表、引导 |
| 中 | 13 / 14 / 14.5 / 15 / 16 / 17px | 正文段落、按钮、卡片标题 |
| 大 | 24 / 28 / 40px + clamp(26–44) | 面板标题、开场 fallback 标题 |

半像素值（10.5/11.5/12.5/14.5）是**有意的视觉微调**，不做合并；
迭代 2 起如需归一，先截图对比再动，且一次只动一档。

## 三、行高分布（17 处）

- 长文阅读：`#guide p` 1.7 / `#cardBio` **2.0**（诗性小传，刻意稀疏，保留）
- UI 紧凑：1–1.5（chips/角标/列表行）
- 结论：**不做全局归一**。行高在本文档登记即可，改动需逐处评审。

## 四、字重与字距

- 字重：300（开场 fallback 标题）/ 600（×14，工作主力）/ 700（×6，强调）；不引入 500。
- 字距（44 处，.04–.5em）：**本项目的核心设计语言**（疏排大写美学），
  有意分 11 档，禁止「顺手统一」。

## 五、数字等宽（v30 新增）

`font-variant-numeric:tabular-nums` 已加于三处动态计数：
`#intro .stats`（开场统计）、`.chip .n`（筛选 chips 计数）、`#lgSeen b`（图鉴进度）。
数字变化时不再横向抖动。后续新增计数器（如护照进度数字）应同样声明。

## 六、变更流程（TL;DR）

1. 复制当代 `make_vXX_baseline.py` 为下一代（或改其补丁表：`U_PATCHES`/`TYPO_PATCHES`，old 唯一 + 次数断言），并把现役模板冻结为 `fixtures/vXX_template.html`
2. 运行新生成脚本 → 重生成 golden/template；上一代脚本 `TEMPLATE_PATH` 改指冻结快照；`--check` 过
3. `unittest discover` 全绿 → 按 pipeline skill §B 重建 `nuc/ demo/` 托管
4. 工厂同步 `app/templates/starmap_v29.html` + 快照（如渲染层有变）→ 全量
5. 05 用 `工厂 scripts/export_v29_product.py` 直出新产物
6. 三仓发版（16 minor / 工厂 minor / 05 patch）
