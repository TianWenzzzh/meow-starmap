## 对任务书第 2 节「已核实事实」的修正（以实测为准）

1. **照片键数 76，不是 195**：photo 分片为 75 张代表照（1 张两猫共用）+ 1 底图；
   194 是「普查实拍总量」文案口径（基准 111 + 补充 83），CSV 照片数量列合计 167。
2. **CALIB 是 54 键不是 76**：22 只在浏览器按 mulberry32(FNV(id)) basePos 落位。
3. **分片数 9 vs 8**：v2.7 手工切 8 片；构建器按工厂贪心 1.5MB 切 9 片，
   仅边界不同，76 数据行字节全等。
4. **图片预算**：v2.7 原片长边 ≤1100、无 EXIF 方向、11 张 207–387KB；
   构建器对合格 JPEG 原样嵌入（0 张重压缩），超限/需旋转才处理。
5. **在线版 `gdfmdvcmsj.coze.site` 已 HTTP 402**：所有发布物料入口改指
   GitHub 仓库与 Pages（已在物料 01 中替换）。
6. **「冬季初雪」不是季节特效**：模板无 snow/season/winter 代码，
   「初雪」是猫名；分叉报告已纠正，避免后续凭空造功能。
7. **v2.7 无可见页脚**：「星位为算法推导」注记的真实形态是 CALIB 上方源码注释 +
   无坐标个体卡片上的「随机分布 · 待校准」pill；字节往返门禁不允许新增页脚字节。
8. git 2.25 不支持 `git init -b`；uv venv 无 pip，装包须用 `uv pip install --python`；
   Playwright 1.63 不支持 Ubuntu 20.04，实测 **1.48.0** 可用。
